# EIT001 — Public surface outside Contract
A feature's public surface IS its `contract/` package. Python has no visibility keyword, so the wall is expressed on the one thing a module can do to another: **import it**. Any import of `pfa.features.<other>.<anything-but-contract>` binds a consumer to things the owning feature meant to keep private, widens the coupling surface, and makes the coupling invisible to anyone grepping the contract. A feature's `module.py` (its plug into the application: `register(bus)`, readiness, warm-up) is public to exactly one consumer, the composition root named by `composition_root` in `[tool.eitri]` (`pfa.application`): there it is allowed; from another feature, or from the entry point `pfa/api`, it is EIT001 like any other internal. The application package (`app_package`, `pfa`) is held to the same wall: its routes consume a feature through `contract/` exactly as another feature would, and nothing in it may import `pfa.features.<x>.internal`.
**Fix:** import the dependency's `contract` package instead, or move the type into `contract/` if it genuinely belongs to the public surface. In the application or its entry point, dispatch the feature's message on the bus instead of reaching for its implementation.
