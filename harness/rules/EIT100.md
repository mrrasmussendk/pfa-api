# EIT100 / EIT101 — Agent context budget
Computes each slice's worst-case agent working set every check:
`own source tokens + Σ dependency Contract API surfaces (reconstructed as stubs) + kernel public surface`.
EIT101 always reports the number (info). EIT100 fails the check when it exceeds `token_budget` (default 15000).
Dependency surfaces are reconstructed from the AST as body-less `.pyi`-shaped stubs (`eitri surface <slice>` prints them) — dependencies' internals cost zero, exactly as the architecture promises. The kernel's public surface is always counted: every slice may import it.
Token counts use a dependency-free estimator calibrated against `o200k_base` (see `docs/calibration.md`); it errs conservative, toward stricter budgets.
**Fix when over budget:** split the slice by sub-capability, split god-contracts into role protocols, or slim the kernel.
