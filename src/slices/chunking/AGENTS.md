# chunking
<!--heimdall:deps-->depends on: (none) + shared_kernel<!--/heimdall:deps-->

Splits text into pieces that fit a model-token budget, cutting on paragraph and sentence boundaries first, then words, then characters. Counts with the model's own tokenizer (`internal/tokenizer.py`, loaded lazily, a few MB — no weights), so the budget is a hard limit, not an estimate.

- Contract: `CountTokens(text) -> int` and `SplitText(text, budget) -> Chunks`. The `embeddings` slice consumes both through the bus; it is this slice's one consumer (see the fan-in column in the root `AGENTS.md`).
- Working set: this folder + `src/shared_kernel/`. The algorithm is pure (`internal/chunker.py` takes a `count_tokens` callable) and unit-tested with whitespace tokens in `tests/api/test_chunking.py`.
- Config: `PFA_EMBED_MODEL` names the tokenizer too, so chunking and embedding always agree. `module.py` exposes `ready()` / `warmup()` for `GET /ready` and `PFA_WARMUP`; the tokenizer is a few MB and loads in well under a second.
