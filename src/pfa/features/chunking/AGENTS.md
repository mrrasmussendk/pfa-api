Splits text into pieces that fit a model-token budget, cutting on paragraph and sentence boundaries first, then words, then characters. Counts with the model's own tokenizer (`internal/tokenizer.py`, loaded lazily, a few MB — no weights), so the budget is a hard limit, not an estimate.

- Contract: `CountTokens(text) -> int` and `SplitText(text, budget) -> Chunks`. The `embeddings` feature consumes both through the bus; it is this feature's one consumer (see the fan-in column in the root `AGENTS.md`).
- Working set: this folder + `src/pfa/kernel/`, plus `src/pfa/api/routes/chunking.py` for an HTTP change. The algorithm is pure (`internal/chunker.py` takes a `count_tokens` callable) and unit-tested with whitespace tokens in `tests/api/test_chunking.py`.
- Config: `PFA_EMBED_MODEL` names the tokenizer too, so chunking and embedding always agree. `module.py` (feature root) registers the handlers and exposes `ready()` / `warmup()` for `GET /ready` and `PFA_WARMUP`; the tokenizer is a few MB and loads in well under a second.
