# EIT002 — Visibility escape hatch is banned
`importlib.import_module(...)`, `__import__(...)`, `sys.path` surgery, writes to `sys.modules`, and `from x import *` all create coupling that neither grep nor Eitri can see. One of them silently reconnects what the architecture separated — and breaks the guarantee that `grep EmbeddingService` finds **every** consumer, which is the property that makes the layout cheap for agents to navigate.
**Fix:** import explicitly, by name, through the Contract. If tests need internals, colocate the tests inside the slice package.
