# EIT001 — Public surface outside Contract
A slice's public surface IS its `contract/` package. Python has no visibility keyword, so the wall is expressed on the one thing a module can do to another: **import it**. Any import of `slices.<other>.<anything-but-contract>` binds a consumer to things the owning slice meant to keep private, widens the coupling surface, and makes the coupling invisible to anyone grepping the contract. `internal/module.py` (the composition-root wiring) is the one exemption: the composition root may import it.
**Fix:** import the dependency's `contract` package instead, or move the type into `contract/` if it genuinely belongs to the public surface.
